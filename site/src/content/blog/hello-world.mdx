## The stack

The site is static [Astro](https://astro.build) output, plus a tiny Express API for the
contact form, privacy-friendly analytics and live GitHub stats. If the API is down, the site
keeps working.

### Code blocks

Syntax highlighting uses Shiki, with separate light and dark themes:

```ts title="shared/github/filter.ts"
export function deriveStatus(repo: { topics?: string[] }): 'shipped' | 'building' {
  if (repo.topics?.includes('lazyninja-shipped')) return 'shipped';
  return 'building';
}
```

```bash
npm run dev   # site on :4321, API on :3000
```

### Controlling projects with topics

Add `lazyninja-featured`, `lazyninja-shipped`, `lazyninja-building` or `lazyninja-hide`
to a GitHub repo and the next build picks it up.
